# 共通プロンプト集

## ベース
学校向け教育アプリ「コツコツの森」のための森アセット。絵本風、やさしい雰囲気、子ども向け、安心感のある色使い。16:9のゲーム画面に置いて自然に見える単体素材として作る。透過背景PNG想定。リアルすぎず、やわらかい水彩調、明るいが派手すぎない。

## 木
木の根元が地面に自然に接する構図。幹と葉が読み取りやすい。森に置いたときに自然に見える大きな木。

## 花
1つの花ではなく、森の中で自然に見える小さな花の集まり。複数の花がふんわり並ぶ。

## 池
森の水辺として自然に見える、やわらかな青緑の池。少し俯瞰した構図。

## 動物
子どもが見て親しみやすい、小さくかわいい動物。森の主役を邪魔しない程度の存在感。
