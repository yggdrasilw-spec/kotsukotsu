# spots.json 設計

## ルール
- 置き場所を先に決める
- 大物は1スポット1つ
- 小物は1スポット複数可
- エリアごとに分ける

## 主なエリア
- forestNorth
- forestWest
- flowerMeadow
- mushroomShade
- pondWest
- rockHill
- pathCenter
- specialSpotArea

## 主なスポット種別
- tree
- flower
- mushroom
- rock
- stump
- bird
- animal_ground
- fish
- insect
- seed
- effect
