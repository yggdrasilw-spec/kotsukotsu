# v20: 先生用ダッシュボードに「児童一覧」を追加

これまでの `teacher.html` は「承認待ちの目標」「クラス全体の活動ログ」「森の記録」は
見られたが、児童ひとりひとりの状態(今日開いたか、目標が進んでいるか、何日連続で来て
いるか)は見えなかった。今回、これを一覧できるダッシュボードを追加した。

## 追加したもの

### `gas/Code.gs`

- `Students` シートに列を追加: `lastLoginAt`, `loginStreak`
  - `migrateHeaders()` により、既存のスプレッドシートでも起動時に自動で列が追記される。
- `touchStudentLogin(student)`: `syncState` が `studentId` 付きで呼ばれたとき、その日
  まだ記録していなければ `lastLoginAt` を更新し、前日からの連続日数なら `loginStreak`
  を+1、そうでなければ1にリセットする。20秒おきのポーリングで毎回書き込むと重いため、
  「その日の最初の1回だけ」書き込むようにしてある。
- `buildStudentsRoster(classCode, studentRows)`: `studentId` **無し**(＝先生からの呼び
  出し)のときだけ計算する集計。児童ごとに以下を算出して返す。
  - `daysSinceLogin` / `loginStreak`
  - `activeGoalsCount`（設定中の目標数）
  - `todayAchieved` / `todayPending`（今日の達成数・承認待ち数）
  - `status`: 下記のいずれか1つ（優先度順）
    1. `needs_support` … 2日以上ログインなし
    2. `never_opened` … 一度もログイン記録なし
    3. `stalled` … 直近3日、承認された達成が0件
    4. `not_opened_today` … 昨日は来たが今日はまだ
    5. `no_goals` … 今日は来たが目標が1つも無い
    6. `in_progress` … 今日は来ていて目標もあるが、まだ達成前
    7. `good` … 今日の目標を1つ以上達成
- `handleSyncState` のレスポンスに `studentsRoster`（配列。児童側の呼び出しでは空配列）
  を追加。既存の `students`（id+nicknameのみ、承認待ち一覧の名前解決用）はそのまま残した。

### `teacher.html` / `js/teacher.js` / `style.css`

- 「クラスコード」パネルの直後に「児童の様子」パネルを新設。
  - 上部にサマリーチップ（🚩要支援／😐停滞／💤未起動／🌱目標なし の人数、全員問題なけれ
    ば「✅ 全員、順調です」）。
  - 「気になる子だけ表示」チェックボックスで、上記5状態の児童だけに絞り込める（ネット
    ワーク再取得はせず、直前に取得した一覧をその場でフィルタし直すだけ）。
  - 児童カードは優先度順（要支援→停滞→未起動→目標なし→がんばり中→達成ずみ）→五十音順
    で並び、名前・状態ラベル・連続日数・最終アクセス・今日の達成数を表示する。

## 未対応・今後の課題

- `lastLoginAt` は「日付が変わった最初のsyncState」でしか更新されないため、同じ日の
  うちの「何時何分に開いたか」は分からない(仕様として「今日開いたか」の粒度で十分という
  判断)。
- `stalled` の3日判定・`needs_support` の2日判定はコード内に固定値として埋め込んで
  あり、先生側から日数を変更する設定画面はまだ無い。
- 実機（実際にGASへデプロイしたスプレッドシート、複数端末からの同時アクセス）でのテスト
  は未実施。特に `touchStudentLogin` は `doPost` 全体を包む `LockService` の直列化に
  乗っかっている前提。
- 既存のスプレッドシートを使っている場合は、GASエディタで最新の `Code.gs` を貼り直して
  再デプロイする必要がある（`migrateHeaders` が起動時に列を追記するので、シート自体を
  作り直す必要はない）。

# v21: 判定日数を先生側で調整可能に + 子ども画面の目標UI刷新

## 1. 「停滞」「要支援」の判定日数を先生が設定できるように

v20時点では「2日以上未起動→要支援」「直近3日達成なし→停滞」が固定値だった。学級の
実情（学年・行事の多さなど）によって適切な日数は変わるため、クラス単位の設定にした。

- `gas/Code.gs`
  - `Classes` シートに `stalledDays` / `supportDays` 列を追加（`migrateHeaders`で自動
    追記、新規クラスは既定値3日/2日で作成）。
  - 新規action `setRosterThresholds`。`buildStudentsRoster()` はこの2値を引数で受け取り、
    ハードコードをやめた。
  - `handleSyncState` が返す `classInfo` に `stalledDays` / `supportDays` を追加。
- `js/api-client.js`: `setRosterThresholds()` を追加。
- `teacher.html` / `js/teacher.js`: クラス設定パネルに2つの数値入力を追加し、
  「設定を保存」ボタンで他の設定と一緒に保存されるようにした。
- `js/teacher.js` の児童カードのラベル文言から具体的な日数（「2日以上」「3日間」）を
  外し、汎用的な表現（「お休みが続いています」等）に変更した。設定日数と表示文言が
  ズレるのを避けるため。

## 2. 子ども画面: 目標パネルの見せ方を刷新

再評価メモの「UI/UXが最重要」「進捗は数字よりも見た目で伝える」「今日の目標を1枚で」
に対応。中身のロジック（達成判定・承認フロー等）は変更せず、表示だけを作り直した。

- `js/render.js` の `renderGoals()`:
  - `renderGoalTodayHero()` を追加。目標パネルの一番上に、全目標の合計進捗を
    円グラフ(conic-gradient、JSライブラリ不要)＋「あと◯つ」のテキストで表示する
    「今日のがんばり」ヘッダーを新設。全部達成すると「今日は全部できたよ！🎉」、
    残り1つになると「あと1つ！」を強調表示する。
  - `renderGoalDots()` を追加。各目標カードに、目標回数ぶんの丸（●できた／◐承認待ち／
    ○まだ）を並べて視覚的に進捗を示す。数字のメタ情報(「きょう 2/3」)はそのまま残し、
    丸と数字の両方で伝える(数字派の子・視覚優先の子どちらにも対応)。
  - 達成しきったカードには `.goal-card--full` を付与し、背景を薄い緑にして視覚的に
    分かるようにした。
- `style.css`: `.goal-today-hero*` / `.goal-dot*` / `.goal-card--full` を追加。
  既存の `.goal-card--celebrate`（達成した瞬間のポップ演出）とは独立したクラスなので、
  演出の競合はない。

### 残っている課題(v21時点)

- 複数目標があるとき、「今日のがんばり」ヘッダー(合計)と個々のカードの丸(単体)の
  2種類の進捗表示が並ぶため、目標が4〜5個(上限)まで増えたときの情報量はまだ様子見。
- 実機（低学年・支援級の児童によるタップ操作、conic-gradientの見え方）での確認は
  未実施。
- 先生設定の `stalledDays` / `supportDays` に、保存時のバリデーションメッセージ
  （例:「1〜14日で入力してください」）はまだ無い（サーバー側でclampはしている）。
